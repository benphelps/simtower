# Asset provenance

This project recreates SimTower using resources extracted from the supplied
Windows executable. Original game artwork, sound and credits belong to
Yoot Saito, OPeNBooK and Maxis, as identified by the game.

The waifu2x textures are locally generated derivatives of that artwork.
The supplied System and Microsoft Sans Serif fonts retain their respective
owners' rights. Inclusion here does not grant ownership of these resources
or apply a new license to them.

The original executable, installation files, native saves, IDA databases,
raw resource dumps and original manual OCR are excluded from version control.
Runtime assets and the authored browser manual are retained intentionally.
