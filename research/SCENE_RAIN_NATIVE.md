## Cloud placement

`B5F0` draws four slots. `B83F` intersects the current viewport with nativeworld[0,360,3000,3888], corresponding to browser[0,−3600,3000,−72]. `B6A5` leaves clouds unchanged only when their full rectangle remains inside this area; clipped/empty slots are regenerated byB717.

`B717` chooses one of900..903 uniformly, before checking fit. If area width≤spritewidth OR height≤spriteheight it empties that slot without rescaling. Otherwise x and y are independent random offsets in[0,areaDimension−spriteDimension−1]. Thus clouds depend on native viewport redraws and RNG, not fixed arbitrary world coordinates. The helper accepts the host's native randomInt; browser rendering cadence should avoid introducing extra regeneration calls on unchanged empty slots.

Native background refresh calls are narrower than all browser renders:
`B3A3` is called only by `F2B2` when arg0=1, reached through `F296` or
scroll/resize code. Successful construction `397C6`, link construction
`18F18`, elevator changes `14911/14BDA`, new/open tower `19C44/1A251` and

car position, clock or rain. Nonstructural native UI refresh commands still
need the explicit `OriginalCloudField.update(...,{dirty:true})` hook.

The extractedRGBPNGs show black strokes because initial rain palette207..218is black;RGB alone loses the distinction between these twelve indexed colors. `tools/extract_scene_indices.py` losslessly preserves original DIBindices in public/assets/scene-indices.json, alongside352/900..903/905 for normal sky palette188..193.

`5EB4` copies sky colors188..193 into BOTH six-color rain banks207..212 and213..218. This conceals rain pixels using their corresponding original sky shades. `56CB` runs on the separate fifteen-unit(GetTickCount>>4) Effects gate, about240milliseconds. With rainflag10 and80<tick<1490 it calls5B3E, which alternates the banks between its six fixed light/dark RGBtriples based on the shared signedWORDcounter's parity. Effects off freezes animation.

`4A256` updates Effects before FD4B/5F8B updates the sky palette.5F8B's sky changes invoke5EB4 again. Rain banks freeze outside the animation window until a new sky palette copies them; in particular1490..1499does not immediately erase the final frame. `OriginalRainColors` preserves this order and frozen-bank behavior. Recoloring edits only original188..193/207..218pixels and preserves alpha, so clouds retain their native transparency.
