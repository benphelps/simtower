# Commercial destination metadata and list lifecycle

Recovered directly from the live IDA Win16 database on 2026-10-14. Implementation: `src/original-commercial-registry.js`; Tower/people/show/metro integration and `tests/commercial-registry-native.test.mjs`.

- **32673** scans 512 eighteen-byte commercial records for floor byte `FF`. It writes floor+0, tenant index+1, state+2, three referral bytes+3..5, remaining+6, generated+7, population+8, inside+9, style+B, next-patron WORD+C, visitors WORD+10. New shops are unleased stateFF; food opening state comes from33737. The tail unconditionally calls334BB, including closed restaurants and unleased shops.
- **334BB /33590** append WORD metadata indices into one of seven per-lobby arrays. Shop arrays have310 words, restaurant150, fastfood230. Native registration uses signed truncation of `(nativeFloor-5)/15`, valid quotient0..6 and remainder<=9. Browser floor is native floor minus10. Empty gaps between lobby bands do not register. List membership is independent of occupancy/state.
- **333BD /33201** choose the home lobby list using signed quotient `(nativeFloor-9)/15` clamped below to0, or the ground list if that local count is zero. One RNG draw chooses one entry; only then does33201 reject stateFF/unleased or3/closed. It does not filter candidates first, retry another business, or fall back when a nonempty local list selected a closed business. It does not test the deleted tenant byte.
- **3C074** commercial demolition writes tenant+1 `FF` only. It preserves floor, metadata state, statistics and destination-list membership. Foreign people retain actor+6. A demolished open establishment remains a selectable failed destination until dawn; metadata capacity is not freed immediately.
- **3BF6D→417F8→41C61** removing a visitor's home frees its own actor pool and clears transport ring/car entries, with office/hotel parking/VIP cleanup. The complete417F8 call graph has no32E4E or2C6B4. An external commercial venue's inside byte is therefore preserved when its customer's home is demolished or destroyed, even though that customer no longer exists. Tower no longer synthesizes a food departure in this path; the next venue opening clears the surviving byte.
- **32024** at tick240 calls333EE to clear **all three** arrays, scans all512 records, frees deleted entries by writing floorFF, and runs32192 on live shops/fastfood. **320F0** at1600 runs32192 only on live restaurants without clearing their list first. **32192** appends each reopened venue using334BB. Consequently, a restaurant completed between those events is already in its list and acquires a second entry at opening. Duplicates are deliberate preserved ordering, not an invalid-save condition.
- **4866D /45FDC** select a WORD index and write only `AL` into actor+6. **32F9E** reads that field with `CBW`: negative values return nativeground10; nonnegative values read registry floor+0, without inspecting tenant+1. Selected metadata128..255 and384..511 becomes negative/offsite;256..383 aliases0..127. An actor that selected a removed record follows the old floor until dawn reclamation; floorFF reads native -1/browser -11; later first-free reuse follows the replacement record's floor and type.
- **32C32** admission rejects deleted/unleased/closed metadata and commits the PART missing penalty through36E17/36B20, retaining metadata floor as actor current floor. A negative/offsite selection takes32DC1 without this missing-record commit or floor mutation. Visitors+10 is a wrapping WORD. Inside+9 is a BYTE, with a signed capacity comparison against40.
- **32E4E** departure checks the currently selected metadata, not a stored admission claim. A live/open destination decrements inside+9 after its current type's visit duration; there is no guard for having been admitted before a reopen/reuse. DEC0 wraps to255. Missing/closed destinations finish immediately without decrement. An offsite destination writes nativeground10 into the actor's current floor when departing, even if initial routing failed and admission had preserved its previous floor.
- **32B45** changes the facade only at exact inside counts: admission1→state1 and10→state2; departure0→state0 and9→state1. Other counts retain the previous state, including byte underflow. Native original sprite selection remains in `original-commercial.js`.
- **28F8x /28FFx /335D1** interpret the stored visitors WORD with signedJGE for food evaluation and receipt tiers. Values32768..65535 are negative and select the bad/loss tier despite their unsigned storage width. **29027** shop evaluation adds signedremainingBYTE to visitorsWORD withWORDwrap, then compares the signed result to20/25 shifted by28EB9 price. This is independent of display-counter storage. Tests cover32767/32768/65535, positive addition crossing32768, and25+65535 wrapping to24.
- **486C5 /46064 /45807** admission retries use the actor's stored current floor and re-read the commercial destination through32F9E before calling3E2A0. A reclaimed/reused slot on another floor therefore requires a new trip rather than teleporting at admission. Same-floor retries commit36B20 before32C32, including raw low-ten-bit stress above300; only an explicit36E17 penalty addition invokes its300 cap. Movie and metro visitors now use the same retry accounting. **457BD** additionally rejects any negative actor+6 directly into metro state39 before transport; unlike office/condo/hotel/movie visitors, metro shoppers do not route negative commercial selectors offsite. **460D7** falls back to offsite state65 on the first failed movie-food route, while a subsequent state65 routing failure takes462C1 and ends that day's visit.

Browser saves retain metadata tombstones, slot assignments, exact ordered arrays (including duplicates), signed actor selectors, and byte/word counters. Save validation checks live ownership, original dimensions and valid referenced list entries. Old browser saves migrate live rooms by build id; their historical deleted records, list insertion order and duplicates cannot be recovered. Native buffer memory corruption from exceeding the original fixed per-band arrays is not emulated; this remains a boundary limitation beyond valid native list capacity.
